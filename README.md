# Steam-NaNo
Lighter than air 

A lightweight, custom-themed Steam library manager and launcher.

## Features
* **Auto-Updater:** Automatically checks for new versions via GitHub.
* **Smart Scanner:** Automatically detects Steam installation and library folders.
* **Modern UI:** Built with CustomTkinter for a sleek, dark-mode experience.
* **Profile Integration:** Displays your active Steam username and avatar.
* **Portable:** Designed to be easily built into a single executable file.
